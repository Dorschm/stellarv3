Audit performed as part of Issue Batch May 12–13 2026 (item #2). Goal: every
difficulty-scaled value must affect only AI Nations / Bots — never humans.

addressed in the same change-set.

| `AttackExecution` relation change (Easy −60 → Impossible −100) | `AttackExecution.ts`           | ❌     | Previous audit assumed Nation-only consumption was sufficient, but `PlayerImpl.playerProfile()` exports each player's relation map and `PlayerPanel` displays a Nation's relation toward the local human via `otherProfile.relations[myPlayer.smallID()]`. The Hard tier was chosen because it's the established "= human baseline" pattern
elsewhere in the file.

## Regression guard

`tests/core/configuration/HumanDifficultyInvariants.test.ts` pins
`maxPopulation`, `troopIncreaseRate`, `creditAdditionRate`, and
`scaleFleetUpkeep` for `PlayerType.Human` to be identical across all four
`Difficulty` values. Add new assertions there for any future difficulty-scaled
config touching humans.

Additional regression coverage:

- `tests/HumanRelationDifficultyInvariant.test.ts` pins the `AttackExecution`
  relation delta for a Human↔Nation attack and the
  `DonateCreditsExecution.getCreditsChunkSize` chunk size for a Human→Nation
  donation to be identical across all four `Difficulty` values, guarding the
  ❌ rows for `AttackExecution` and `DonateCreditsExecution` above.
